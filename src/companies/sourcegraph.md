## Company blurb

Sourcegraph is a code intelligence platform that empowers developers and AI agents to search, understand, and automate changes across large codebases. Their products include deep code search, batch changes for large-scale cross-repository modifications, and code insights for analytics across repositories.

## Remote status

Sourcegraph is an all-remote, asynchronous-first company, hiring talent worldwide regardless of geographic location.
