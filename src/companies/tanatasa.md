## Company blurb

[Tanatasa](https://tanatasa.sg) is a Singapore ecommerce company built for agentic shopping. Shoppers buy everyday essentials (pantry, household, health, personal care, beauty, baby and pet) on the website, or hand a restock list to an AI assistant that searches the catalogue, compares options, builds the cart and hands checkout back for the shopper to approve. AI assistants connect through a public agent API and an MCP server.

## Company size

1-10 employees.

## Remote status

Tanatasa is remote-friendly. Engineering roles such as the [AI Engineer (Remote)](https://tanatasa.sg/career/ai-engineer-remote) role are fully remote and salaried. The team works asynchronously in writing (design notes, pull requests, chat) and asks remote engineers for at least 4 hours of overlap with Singapore time (UTC+8). Commercial and content roles are based in our Singapore office.

## Region

Asia-Pacific. Remote engineers can be based in Singapore, Malaysia, Indonesia, the Philippines, Vietnam, Thailand, India, Sri Lanka, Australia or New Zealand.

## Company technologies

* TypeScript, React and React Router for the storefront
* Cloudflare Workers, Pages, D1 (SQLite) and R2
* Model Context Protocol (MCP) server and REST agent API for AI assistants
* LLM pipelines and evals for product data and agent search, in TypeScript and Python
* Stripe for payments, Vitest for testing, GitHub for code
